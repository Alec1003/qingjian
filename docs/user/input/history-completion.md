---
title: 历史补全
order: 7
description: 用以前输入过的句子补全当前拼音，按出现次数挑选，不联网。
---

输入拼音时，若高亮的候选是以前上过屏的一句话的开头，这句话会出现在拼音右侧。同一个开头对上好几句时，出现次数多的那句优先；次数相同则用最近的一句。继续打字则这句话换掉或消失。

Windows 上打开了「数字键进暂存区」时，先用数字键把当前的词收进暂存区。暂存区下面会列出以前上过屏、并且以这段文字开头的更长句子，出现次数多的排在前面，次数相同则最近的在前。用 `Ctrl + 数字` 把选中的一句放进暂存区；这时普通数字仍是句子里的字，可以接着打出「今天是1号」。`Enter` 写入应用，`Space` 直接写入高亮的那一句。没开这项时，`Tab` 直接把出现次数最多的一句写入应用。macOS 与 Linux 上 `Tab` 直接写入出现次数最多的一句。

它只对照这台电脑上通过青简写进应用的文字，不向任何服务发送内容。一次写进去的整段记成一句：几个词先放进暂存区，回车或空格写出去时记的是这一整段，不把每个词拆开。前后两次按键各自写出去的文字不会拼成一条。至少要对上两个字。只有一个字时不提示，`Tab` 仍用来翻页。

英文模式里 `Tab` 仍用来选中高亮的英文词，不采用历史补全。暂存区里还有词时也不提示。密码框和声明为私密的输入框里不记录。

「设置 → 候选」的「历史补全」缺省打开。关掉后不再记录、也不再提示；已经记下的句子还在，重新打开后可以继续用。要从这台电脑上删掉，删除数据目录里的 `phrase-history.txt`（位置见 [数据与日志](../help/data-and-logs.md)）。

云联想的整句补全也画在同一位置。两者同时能给出时，显示以前输入过的那一句。
